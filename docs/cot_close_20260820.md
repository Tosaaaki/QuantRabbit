# COT positioning does not help the operator model

The 2026-08-07 log left non-price inputs as one of two remaining doors, with
CFTC Commitments of Traders named as the cheapest — free, public, structured,
weekly, and never tested here. Unlike news it has a full history, so its
contribution is measurable against the existing 2,688 rows today rather than
after a forward test.

## Result

Seven positioning features added to the 52 price features, same walk-forward,
same absolute threshold:

| split | price only, mean / LB | **+ COT, mean / LB** |
|---|---|---|
| 50% | +79.08 / +61.03 | **−21.88 / −34.88** |
| 60% | +67.59 / +43.16 | **−61.28 / −75.88** |
| 70% | +46.24 / +18.30 | **−27.02 / −44.96** |
| 80% | +60.38 / +24.95 | **−9.33 / −32.99** |
| average | **+63.32** | **−29.88** |

Every split turns negative. The firing count also roughly doubles (163→385 at
the 70% split), so the positioning features shift the score distribution enough
that the frozen absolute threshold starts admitting signals the price model
would have declined — and those additions lose.

## Why, and what it implies for the rest of the door

COT is weekly and slow, so within a week it is close to a constant: it adds
dimensions without adding decisions. And the model is already saturated —
52 features against 464 positives is about nine positives per feature, which is
thin before anything is added.

That is a warning about the whole non-price programme, not just this input.
News and the event calendar bolted on as extra features to the same model would
face the same arithmetic. If a non-price input is to contribute here it has to
be an independent signal tested on its own, not another column.

## Cost of finding out

One hour, because COT has history and could be tested retroactively. Building
the layer first and waiting for the registered 60 forward signals would have
reached the same answer in about three months.

## Data notes

Two contract names silently return nothing: `NEW ZEALAND DOLLAR` and
`U.S. DOLLAR INDEX` both stop at 2022-02-01 after a CFTC rename. NZD is now
`NZ DOLLAR`; the dollar index has no live successor in this dataset, so USD
positioning is derived as the open-interest-weighted negative of the other
seven currencies — every contract is quoted against USD, so long yen futures is
short dollars.

Release timing is enforced: a report dated Tuesday is only visible from the
Friday 20:00 UTC release. Verified — a lookup one minute before the release
returns the previous week's report, one minute after returns the new one.
